EduMetrics — Student Performance Analysis
About the Project
EduMetrics is a beginner-friendly data analysis project that explores student performance using Python. It analyzes marks across different subjects and departments to identify performance trends.
Features
Loads student data from a CSV file using Pandas.
Calculates total and average marks.
Identifies top-performing students.
Finds students with an average below 60.
Compares department performance.
Visualizes data using Matplotlib bar charts, histograms, and scatter plots.
Checks missing values, duplicate rows, and invalid Maths marks.
Technologies Used
Python
Pandas
Matplotlib
